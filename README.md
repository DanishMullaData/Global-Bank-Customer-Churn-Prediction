Global Bank Customer Churn Prediction
End-to-end Data Science & AI project using Python, XGBoost, and Power BI

Project Overview:
This project focuses on predicting customer churn for a global bank using advanced machine learning techniques and delivering insights through a dynamic Power BI dashboard.
The system identifies customers likely to leave the bank and helps stakeholders take proactive actions such as targeted offers, retention strategies, and credit score monitoring.

Key Features
✅ Machine Learning
Built using Python, Pandas, NumPy, Seaborn, Matplotlib
Model: XGBoost Classifier (High performance on classification tasks)
Evaluated using Accuracy, Precision, Recall, F1 Score
Exported model predictions for Power BI visualization

✅ Power BI Dashboard
Includes:
Churn count by gender
Churn by geography
Churn trend by credit score
Age vs churn patterns
Customer engagement metrics
Business recommendations
Interactive filters for Age, Gender, Geography, Active Member Status

🌍 Insights
Female customers churn more frequently
France shows the highest churn rate
Customers with lower credit scores churn more
Customers aged 40–55 show higher churn
Inactive members churn heavily
Customers with 1 product have the highest churn risk
